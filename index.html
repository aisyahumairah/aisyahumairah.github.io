Homestay Booking System

HomeLodge

Full stack developerUTM Final Year Project

Booking and management platform for a homestay business. Guests book and pay online and get a QR door key for their stay, while hosts, housekeepers and a Super Admin each work from their own view.

  • Built a booking engine that checks availability against confirmed stays, unpaid holds and blocked dates, with row locks so two guests can never book the same dates.
  • Issued a QR door key for every booking, valid from check-in to check-out. The smart lock checks each scan with the server, so revoking or extending a key takes effect immediately.
  • Built a housekeeping module: cleaning jobs are created from booking events, housekeepers get job-only door access, checklists and photos, and the next guest's key is released only after the unit is cleaned.
  • Integrated online payments behind a gateway contract (ToyyibPay and a sandbox driver) with PDF receipts, tiered refund rules and webhook handling that safely ignores gateway retries.
  • Grew the system into a multi-operator marketplace with host applications, Super Admin approval, earnings and payouts, without migrating any existing data.
  • Implemented role-based access and data isolation with Spatie Permission across four roles. Records outside a user's scope return 404, so operators can't see each other's data.
  • Added real-time guest and host chat with Laravel Reverb, 21 notification types, Google Calendar sync, and occupancy and revenue reports exported to PDF, CSV and XLSX.
  • Logged every significant action to an append-only audit trail and covered the system with 328 passing PHPUnit feature tests.
